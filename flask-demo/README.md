取代 FROZEN 版（E=230 写死、无双校验、无回滚）——本版以母版公式为唯一依据：

## 运行

```bash
pip install flask          # 若未装
python test_engine.py      # 验收钉子：26 条全绿再动手录屏
python app.py              # http://127.0.0.1:5000
```

**一键启动：双击 `启动e日金.bat`**（自动清理端口残留 → 起服务 → 3 秒后自动开浏览器）；录完双击 `停止e日金.bat` 收尾。

## 演示动线（录屏参考，数字全部来自母版）

1. 打开 → 顶栏徽章「基础约束状态 · 水库<500」——新用户从头开始，仅 L1-L2 可选（母版 3.3 状态门槛）
2. 输入 M=1500 → Kmax ¥820 → 选 L2（¥100）→ 锁定并开始（新用户只能锁 L1-L2，这是母版规则）
3. 拆分 430 + 100 + 870 + 100 = 1500 ✓；第 1 天额度 +¥30
4. 消费 ¥23 → 今日剩余 ¥7；⏩24h → 「余量 ¥7 荧光标记入回滚池（池 7/500）」
5. 消费 ¥30 → 余 0；⏩24h → 第 3 天 +30（无余量）；🔧 回滚池→¥497；消费 ¥26 → 余 4；⏩24h → 三连事件：
   余量 4 入池（497+4=501）→ 开闸 ¥500 入水库 → 超额缓冲 ¥1 归用户、池归零
6. ⏩⏩ 快进至第 30 天 → 放纵日（W = 100 + 0.5×R₋₁，替代当天日发）→ ⏩ 关账：
   刚需池入水库、回滚池结转、放纵日余额滚存
7. 退出 → 「锁定资金 ¥X（含历史固化）+ 回滚池 ¥Y 已全额回到可用——一分不少」
